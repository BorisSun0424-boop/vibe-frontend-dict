# 给 Vibe Coding 小白的前端效果词典 · 网页版

一本可以「边看边点」的前端效果词典：80 个常见前端效果词条，分 7 大类，每个词条都配一个**真实可交互的效果预览**和一句可以直接改着用的 prompt。

纯静态页面，零依赖、无构建步骤，双击 `index.html` 就能打开。

## 目录结构

```
vibe-frontend-dict/
├── index.html          # 整个页面（HTML + CSS + JS 单文件）
├── assets/             # 原文配图（84 张：封面、词条示意图、结语插画）
└── README.md
```

## 功能

- **80 个可交互效果预览** —— 下拉菜单真的能点开、弹窗真的能弹出、走马灯真的在滚、打字机真的在打字
- **原文配图** —— 每个词条在 prompt 下方附原文示意图，点击可放大（支持 Esc 关闭）
- **搜索** —— 中英文都能搜，支持按 `/` 快捷键聚焦搜索框
- **左侧目录** —— 滚动自动高亮，另有常用入口一键跳转
- **一键复制 prompt** —— 复制后右下角弹提示
- **阅读进度条 / 回到顶部 / 卡片入场动画**
- 适配手机端，并支持系统「减少动态效果」设置

## 本地打开

直接双击 `index.html`，或用任意静态服务器：

```bash
python3 -m http.server 8000
# 然后访问 http://localhost:8000
```
